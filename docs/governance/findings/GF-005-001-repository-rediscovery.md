# GF-005-001

## Title

Repository Rediscovery significantly improves AI repository alignment.

---

## Status

Open

---

## Introduced

Sprint 005

---

## Observation

During Sprint 005, an AI contributor initially reconstructed an obsolete understanding of Sprint 005 and proposed runtime implementation that had already been removed from the approved Execution Contract.

After beginning a completely new engineering session and explicitly requiring Repository Rediscovery, the contributor reconstructed the current repository state correctly.

The engineering proposal then became fully aligned with the approved Execution Contract.

---

## Evidence

Observed using Antigravity CLI.

Without Repository Rediscovery:

- obsolete Sprint 005 scope
- runtime implementation
- RepositoryManager changes
- statistics metadata

After Repository Rediscovery:

- correct Sprint identified
- correct scope identified
- correct governing artifacts
- correct Execution Contract

---

## Engineering Impact

Repository Rediscovery significantly reduces historical context contamination.

---

## Recommendation

Consider introducing Repository Rediscovery as a mandatory gate before engineering planning for independent AI contributors.

Not yet resolved.
